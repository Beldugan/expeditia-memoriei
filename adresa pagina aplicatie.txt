Nume sugerat pentru repository: expeditia-memoriei

Comenzile, o singură dată, din folderul aplicației:

    git init
    git add .
    git commit -m "Prima versiune"
    git branch -M main
    git remote add origin https://github.com/Beldugan/expeditia-memoriei.git
    git push -u origin main

Adresa repository-ului:
https://github.com/Beldugan/expeditia-memoriei.git

Pagina live (Settings -> Pages -> Source: GitHub Actions):
https://beldugan.github.io/expeditia-memoriei/

Până atunci aplicația merge local: dublu-click pe index.html.
